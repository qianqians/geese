# WGSL 反射 + 声明式管线编排 — 完整技术设计

## 1. 架构总览

```
TOML stage list: [["shader1.cs", "shader2.vs", "shader3.cs", "shader2.fs"]]
    ↓
pipeline_compiler.rs (新增)
    ├─ Phase 拆分（vs/fs → render, cs → compute）
    ├─ 调用 reflect.rs 获取每个 shader 的元数据
    ├─ 统一顶点布局合并（跨 phase 的 @location 并集）
    ├─ Binding 合并去重 → BindGroupLayout descriptors
    └─ 输出 CompiledPipeline
    ↓
reflect.rs (新增)
    ├─ naga::front::wgsl::parse_str() → 结构化元数据
    ├─ 文本扫描 → entry point body 源码文本
    ├─ naga TypeInner → WgslType 映射
    └─ 顶点属性反射（struct/inline/builtin 三种模式）
    ↓
core.rs (扩展) + stream.rs (已有) + compose.rs (扩展)
    └─ 新增类型 + ShaderModule.vertex_attributes 字段
```

```rust
// crates/shader_framework/src/reflect.rs

use crate::core::*;
use crate::stream::*;
use crate::generator::{ConstantDef, GlobalVarDef, AddressSpace};

/// 从 WGSL 源码反射提取所有元数据。
///
/// `source` 必须是可被 naga 独立解析的完整 WGSL（含所有依赖声明）。
/// 对于跨文件依赖的 shader，调用方需先拼接依赖源码（如 pbr_common + forward_plus）。
pub fn reflect_module(name: &str, source: &str) -> ShaderResult<ReflectedModule> {
    let naga_module = naga::front::wgsl::parse_str(source)
        .map_err(|e| ShaderError::Reflect { message: format!("naga parse: {e}") })?;
    
    let entry_points = extract_entry_points(&naga_module);
    let bindings = extract_bindings(&naga_module);
    let structs = extract_structs(&naga_module);
    let functions = extract_functions(&naga_module);
    let constants = extract_constants(&naga_module);
    let global_vars = extract_global_vars(&naga_module);
    let vertex_attributes = extract_vertex_attributes(&naga_module);
    
    // 文本提取 entry point body（naga 不提供源码文本）
    let vertex_body = extract_entry_point_body(source, &entry_points, ShaderStage::Vertex);
    let fragment_body = extract_entry_point_body(source, &entry_points, ShaderStage::Fragment);
    let compute_body = extract_entry_point_body(source, &entry_points, ShaderStage::Compute);
    
    Ok(ReflectedModule { name, entry_points, bindings, structs, functions,
        constants, global_vars, vertex_attributes, vertex_body, fragment_body, compute_body })
}

/// 反射结果 — 与 ShaderModule 字段对齐，可直接转换。
```

### 3.2 naga TypeInner → WgslType 完整映射

```rust
fn type_inner_to_wgsl_type(inner: &naga::TypeInner, types: &naga::UniqueArena<naga::Type>) -> Option<WgslType> {
    match inner {
        TypeInner::Scalar(s) => match (s.kind, s.width) {
            (ScalarKind::Float, 4) => Some(WgslType::F32),
            (ScalarKind::Sint, 4) => Some(WgslType::I32),
            (ScalarKind::Uint, 4) => Some(WgslType::U32),
            (ScalarKind::Bool, 1) => Some(WgslType::Bool),
            _ => None, // f16, f64 不支持
        },
        TypeInner::Vector { size, scalar } => {
            let st = scalar_kind_to_wgsl(scalar)?;
            match size {
                VectorSize::Bi => Some(WgslType::Vec2(st)),
                VectorSize::Tri => Some(WgslType::Vec3(st)),
                VectorSize::Quad => Some(WgslType::Vec4(st)),
            }
        },
        TypeInner::Matrix { columns, rows, scalar } => {
            // 仅支持方阵 + mat4x4/mat3x3/mat2x2
            let st = scalar_kind_to_wgsl(scalar)?;
            match (columns, rows) {
                (VectorSize::Bi, VectorSize::Bi) => Some(WgslType::Mat2x2(st)),
                (VectorSize::Tri, VectorSize::Tri) => Some(WgslType::Mat3x3(st)),
                (VectorSize::Quad, VectorSize::Quad) => Some(WgslType::Mat4x4(st)),
                _ => Some(WgslType::Custom(format_matrix_type(columns, rows, st))),
            }
        },
        TypeInner::Array { base, size, .. } => {
            let elem = type_inner_to_wgsl_type(&types[*base].inner, types)?;
            let n = match size {
                ArraySize::Constant(c) => Some(c.get()),
                ArraySize::Dynamic => None,
            };
            Some(WgslType::Array(Box::new(elem), n))
        },
        TypeInner::Struct { .. } => {
            // 用 type name 引用
            None // 调用方需从 types arena 获取 name
        },
        TypeInner::Image { dim, arrayed, class } => {
            Some(image_class_to_wgsl_type(dim, *arrayed, class))
        },
        TypeInner::Sampler { comparison } => Some(WgslType::Sampler),
        _ => None,
    }
}
```

### 3.3 Entry Point 提取

```rust
fn extract_entry_points(module: &naga::Module) -> Vec<EntryPointInfo> {
    module.entry_points.iter().map(|ep| {
        let stage = match ep.stage {
            naga::ShaderStage::Vertex => ShaderStage::Vertex,
            naga::ShaderStage::Fragment => ShaderStage::Fragment,
            naga::ShaderStage::Compute => ShaderStage::Compute,
        };
        let workgroup_size = if ep.stage == naga::ShaderStage::Compute {
            Some(ep.workgroup_size)
        } else { None };
        let parameters = ep.function.arguments.iter().map(|arg| {
            ParameterInfo {
                name: arg.name.clone().unwrap_or_default(),
                ty: resolve_type_handle(arg.ty, &module.types),
                binding: arg.binding.as_ref().map(|b| match b {
                    naga::Binding::BuiltIn(bi) => ParameterBinding::Builtin(format!("{:?}", bi)),
                    naga::Binding::Location { location, .. } => ParameterBinding::Location(*location),
                }),
            }
        }).collect();
        EntryPointInfo { name: ep.name.clone(), stage, workgroup_size, parameters }
    }).collect()
}
```

### 3.4 顶点属性反射（三种模式）

```rust
fn extract_vertex_attributes(module: &naga::Module) -> Vec<VertexAttributeInfo> {
    // 找到 @vertex entry point
    let vs_ep = module.entry_points.iter()
        .find(|ep| ep.stage == naga::ShaderStage::Vertex)?;
    
    let mut attrs = Vec::new();
    let mut offset: u64 = 0;
    let mut has_instance = false;
    
    for arg in &vs_ep.function.arguments {
        match &arg.binding {
            // 模式 B: inline @location(N) 参数
            Some(naga::Binding::Location { location, .. }) => {
                let ty = resolve_type_handle(arg.ty, &module.types);
                let name = arg.name.clone().unwrap_or_default();
                let format = ty.to_vertex_format().unwrap_or(wgpu::VertexFormat::Float32x4);
                let attr = VertexAttributeInfo {
                    name: name.clone(),
                    location: *location,
                    ty: ty.clone(),
                    format,
                    offset,
                    semantic: infer_semantic(&name),
                    step_mode: wgpu::VertexStepMode::Vertex,
                };
                offset += ty.byte_size();
                attrs.push(attr);
            }
            // 模式 C: @builtin(instance_index) 等
            Some(naga::Binding::BuiltIn(_)) => {
                has_instance = true;
                // builtin 参数不产生 vertex attribute
            }
            // 模式 A: struct 参数 — 展开 struct members
            None => {
                if let naga::TypeInner::Struct { members, .. } = &module.types[arg.ty].inner {
                    for member in members {
                        if let Some(naga::Binding::Location { location, .. }) = &member.binding {
                            let ty = resolve_type_handle(member.ty, &module.types);
                            let name = member.name.clone().unwrap_or_default();
                            let format = ty.to_vertex_format().unwrap_or(wgpu::VertexFormat::Float32x4);
                            let attr = VertexAttributeInfo {
                                name: name.clone(),
                                location: *location,
                                ty: ty.clone(),
                                format,
                                offset, // 按 struct member 声明顺序累加
                                semantic: infer_semantic(&name),
                                step_mode: wgpu::VertexStepMode::Vertex,
                            };
                            offset += ty.byte_size();
                            attrs.push(attr);
                        }
                    }
                }
            }
        }
    }
    attrs
}
```

### 3.5 StreamSemantic 推断

```rust
fn infer_semantic(name: &str) -> StreamSemantic {
    let lower = name.to_lowercase();
    match lower.as_str() {
        "position" | "pos" | "in_pos" => StreamSemantic::Position,
        "normal" | "nrm" | "in_normal" => StreamSemantic::Normal,
        "tangent" | "tan" | "in_tangent" => StreamSemantic::Tangent,
        "joints" | "bone_indices" | "bone_ids" => StreamSemantic::BoneIndices,
        "weights" | "bone_weights" => StreamSemantic::BoneWeights,
        _ if lower.starts_with("uv") || lower.starts_with("texcoord") => {
            let idx = lower.chars().filter(|c| c.is_ascii_digit()).collect::<String>()
                .parse().unwrap_or(0);
            StreamSemantic::UV(idx)
        }
        _ if lower.starts_with("color") || lower.starts_with("col") => {
            let idx = lower.chars().filter(|c| c.is_ascii_digit()).collect::<String>()
                .parse().unwrap_or(0);
            StreamSemantic::Color(idx)
        }
        _ => StreamSemantic::Custom(name.to_string()),
    }
}
```

### 3.6 文本 Body 提取

```rust
/// 花括号深度扫描 — 找到匹配的 } 位置。
/// 跳过 // 行注释和 /* */ 块注释中的花括号。
fn find_brace_block(source: &str, open_pos: usize) -> Option<(usize, usize)> {
    let bytes = source.as_bytes();
    let mut depth = 0i32;
    let mut i = open_pos;
    let mut in_line_comment = false;
    let mut in_block_comment = false;
    
    while i < bytes.len() {
        // 处理注释状态
        if in_line_comment {
            if bytes[i] == b'\n' { in_line_comment = false; }
            i += 1; continue;
        }
        if in_block_comment {
            if i + 1 < bytes.len() && &bytes[i..i+2] == b"*/" {
                in_block_comment = false; i += 2; continue;
            }
            i += 1; continue;
        }
        // 检测注释开始
        if i + 1 < bytes.len() {
            if &bytes[i..i+2] == b"//" { in_line_comment = true; i += 2; continue; }
            if &bytes[i..i+2] == b"/*" { in_block_comment = true; i += 2; continue; }
        }
        // 花括号计数
        match bytes[i] {
            b'{' => { depth += 1; if depth == 1 { /* 记录 body 起始位置 */ } }
            b'}' => { depth -= 1; if depth == 0 { return Some((open_pos + 1, i)); } }
            _ => {}
        }
        i += 1;
    }
    None
}

/// 从源码中提取指定 entry point 函数的 body 文本。
fn extract_entry_point_body(
    source: &str,
    entry_points: &[EntryPointInfo],
    stage: ShaderStage,
) -> Option<WgslFragment> {
    let ep = entry_points.iter().find(|e| e.stage == stage)?;
    // 用 regex 定位 "fn <name>(" 的位置
    let pattern = format!(r"fn\s+{}\s*\(", regex::escape(&ep.name));
    let re = regex::Regex::new(&pattern).ok()?;
    let m = re.find(source)?;
    // 从 fn 声明后找到 { 开始位置
    let brace_start = source[m.end()..].find('{')? + m.end();
    let (body_start, body_end) = find_brace_block(source, brace_start)?;
    let body = &source[body_start..body_end];
    Some(WgslFragment::new(body.trim()))
}

/// 去除 body 中的 var output: Type; 和 return output; 样板行。
fn strip_vertex_boilerplate(body: &str) -> String {
    let lines: Vec<&str> = body.lines().collect();
    let filtered: Vec<&str> = lines.into_iter()
        .filter(|line| {
            let trimmed = line.trim();
            !trimmed.starts_with("var output") && trimmed != "return output;"
        })
        .collect();
    filtered.join("\n")
}
```

### 3.7 Binding 提取

```rust
fn extract_bindings(module: &naga::Module) -> Vec<ShaderBinding> {
    module.global_variables.iter()
        .filter_map(|(_, gv)| {
            let binding = gv.binding.as_ref()?;
            let name = gv.name.clone().unwrap_or_default();
            let resource_type = classify_resource(gv, &module.types);
            let visibility = match gv.space {
                naga::AddressSpace::Uniform => ShaderStages::all(),
                naga::AddressSpace::Storage { .. } => ShaderStages::all(),
                naga::AddressSpace::Handle => ShaderStages::FRAGMENT, // 纹理/采样器通常 FS 用
                _ => ShaderStages::all(),
            };
            Some(ShaderBinding {
                group: binding.group,
                binding: binding.binding,
                name,
                resource_type,
                visibility,
            })
        })
        .collect()
}

fn classify_resource(gv: &naga::GlobalVariable, types: &naga::UniqueArena<naga::Type>) -> BindingResourceType {
    match gv.space {
        naga::AddressSpace::Uniform => BindingResourceType::UniformBuffer,
        naga::AddressSpace::Storage { access } => BindingResourceType::StorageBuffer {
            read_only: !access.contains(naga::StorageAccess::STORE),
        },
        naga::AddressSpace::Handle => {
            match &types[gv.ty].inner {
                naga::TypeInner::Image { dim, arrayed, class } => {
                    // 区分 Sampled / Depth / Storage texture
                    match class {
                        naga::ImageClass::Sampled { kind, multi } => {
                            BindingResourceType::Texture {
                                dimension: image_dim_to_texture_dim(dim, *arrayed),
                                sample_type: scalar_kind_to_sample_type(*kind),
                            }
                        }
                        naga::ImageClass::Depth { .. } => {
                            BindingResourceType::Texture {
                                dimension: TextureDimension::D2, // 简化
                                sample_type: TextureSampleType::Depth,
                            }
                        }
                        naga::ImageClass::Storage { format, access } => {
                            BindingResourceType::StorageTexture {
                                dimension: image_dim_to_texture_dim(dim, *arrayed),
                                format: format!("{:?}", format),
                                access: format!("{:?}", access),
                            }
                        }
                    }
                }
                naga::TypeInner::Sampler { comparison } => {
                    BindingResourceType::Sampler(if *comparison { SamplerType::Comparison } else { SamplerType::Filtering })
                }
                _ => BindingResourceType::UniformBuffer, // fallback
            }
        }
        _ => BindingResourceType::UniformBuffer,
    }
}
```

### 3.8 Struct / Function / Constant 提取

```rust
fn extract_structs(module: &naga::Module) -> Vec<StructDef> {
    module.types.iter()
        .filter_map(|(_, ty)| {
            let name = ty.name.as_ref()?;
            match &ty.inner {
                naga::TypeInner::Struct { members, .. } => {
                    let fields = members.iter().map(|m| {
                        let field_name = m.name.clone().unwrap_or_default();
                        let field_ty = resolve_type_handle(m.ty, &module.types);
                        let attrs = m.binding.as_ref().map(|b| match b {
                            naga::Binding::Location { location, .. } => 
                                vec![StructFieldAttribute::Location(*location)],
                            naga::Binding::BuiltIn(bi) => 
                                vec![StructFieldAttribute::Builtin(format!("{:?}", bi))],
                        }).unwrap_or_default();
                        StructField { name: field_name, ty: field_ty, attributes: attrs }
                    }).collect();
                    Some(StructDef { name: name.clone(), fields })
                }
                _ => None,
            }
        })
        .collect()
}

fn extract_constants(module: &naga::Module) -> Vec<ConstantDef> {
    module.constants.iter()
        .filter_map(|(_, c)| {
            let name = c.name.as_ref()?;
            let ty = resolve_type_handle(c.ty, &module.types);
            let value = resolve_literal_value(module, c.init);
            Some(ConstantDef {
                name: name.clone(),
                ty,
                id: 0,
                default_value: value,
                is_const: true,
            })
        })
        .collect()
}

fn extract_functions(module: &naga::Module) -> Vec<FunctionDef> {
    module.functions.iter()
        .filter_map(|(_, f)| {
            let name = f.name.as_ref()?;
            let params = f.arguments.iter().map(|a| {
                let pname = a.name.clone().unwrap_or_default();
                let pty = resolve_type_handle(a.ty, &module.types);
                (pname, pty)
            }).collect();
            let ret = f.result.as_ref().map(|r| resolve_type_handle(r.ty, &module.types));
            // body 文本通过文本提取获取（在 extract_entry_point_body 中）
            Some(FunctionDef {
                name: name.clone(),
                parameters: params,
                return_type: ret,
                body: WgslFragment::new(""), // body 由文本提取填充
                overridable: false,
            })
        })
        .collect()
}
```

```rust
/// Metadata about a shader entry point, extracted via naga.
#[derive(Debug, Clone)]
pub struct EntryPointInfo {
    pub name: String,
    pub stage: ShaderStage,
    pub workgroup_size: Option<[u32; 3]>,
    pub parameters: Vec<ParameterInfo>,
}

/// A single parameter of an entry point function.
#[derive(Debug, Clone)]
pub struct ParameterInfo {
    pub name: String,
    pub ty: WgslType,
    pub binding: Option<ParameterBinding>,
}

/// Binding attribute on an entry point parameter.
#[derive(Debug, Clone)]
pub enum ParameterBinding {
    Location(u32),
    Builtin(String),
}

/// Vertex input attribute metadata, reflected from @vertex entry point.
#[derive(Debug, Clone)]
pub struct VertexAttributeInfo {
    /// Field name (e.g. "position", "normal").
    pub name: String,
    /// @location(N) index.
    pub location: u32,
    /// WGSL type.
    pub ty: WgslType,
    /// Corresponding wgpu vertex format.
    pub format: wgpu::VertexFormat,
    /// Byte offset within vertex struct.
    pub offset: u64,
    /// Inferred stream semantic.
    pub semantic: StreamSemantic,
    /// Vertex or Instance step mode.
    pub step_mode: wgpu::VertexStepMode,
}

/// Complete vertex buffer layout descriptor.
#[derive(Debug, Clone)]
pub struct VertexLayoutDescriptor {
    pub attributes: Vec<VertexAttributeInfo>,
    pub stride: u64,
    pub has_instance_data: bool,
}

impl VertexLayoutDescriptor {
    /// Convert to wgpu::VertexBufferLayout (per-vertex attributes only).
    pub fn to_wgpu_vertex_layout(&self) -> wgpu::VertexBufferLayout<'static> {
        let attrs: Vec<wgpu::VertexAttribute> = self.attributes.iter()
            .filter(|a| a.step_mode == wgpu::VertexStepMode::Vertex)
            .map(|a| wgpu::VertexAttribute {
                format: a.format,
                offset: a.offset,
                shader_location: a.location,
            })
            .collect();
        wgpu::VertexBufferLayout {
            array_stride: self.stride,
            step_mode: wgpu::VertexStepMode::Vertex,
            attributes: attrs.leak(), // 'static lifetime
        }
    }

    /// Convert to StreamDeclarations for StreamRouter integration.
    pub fn to_stream_declarations(&self) -> Vec<StreamDeclaration> {
        self.attributes.iter()
            .filter(|a| a.step_mode == wgpu::VertexStepMode::Vertex)
            .map(|a| StreamDeclaration {
                semantic: a.semantic.clone(),
                wgsl_type: a.ty.clone(),
                location: Some(a.location),
                name: a.name.clone(),
                stage: StreamStage::VertexOnly,
            })
            .collect()
    }
}
```

### 6.2 Phase 拆分算法

```rust
fn split_phases(steps: &[String], modules: &HashMap<String, ReflectedModule>) -> Vec<ExecutionPhase> {
    let mut phases = Vec::new();
    let mut current_vs: Option<String> = None;
    let mut current_fs: Option<String> = None;
    let mut current_bindings: Vec<ShaderBinding> = Vec::new();
    
    for step in steps {
        let (module_name, stage_hint) = parse_step_reference(step); // "shader.vs" → ("shader", "vs")
        let module = &modules[&module_name];
        let ep_stage = determine_stage(module, &stage_hint);
        
        match ep_stage {
            ShaderStage::Compute => {
                // 先 flush 当前 render phase
                if current_vs.is_some() || current_fs.is_some() {
                    phases.push(flush_render_phase(&mut current_vs, &mut current_fs, &mut current_bindings));
                }
                // 独立 compute phase
                let wgs = module.entry_points.iter()
                    .find(|e| e.stage == ShaderStage::Compute)
                    .and_then(|e| e.workgroup_size)
                    .unwrap_or([1, 1, 1]);
                phases.push(ExecutionPhase::Compute {
                    shader: module_name.clone(),
                    entry_point: "cs_main".into(),
                    workgroup_size: wgs,
                    bindings: module.bindings.clone(),
                    vertex_location_subset: Vec::new(),
                });
            }
            ShaderStage::Vertex => {
                // 如果已有 VS，flush 当前 render phase
                if current_vs.is_some() {
                    phases.push(flush_render_phase(&mut current_vs, &mut current_fs, &mut current_bindings));
                }
                current_vs = Some(module_name.clone());
                current_bindings.extend(module.bindings.iter().cloned());
            }
            ShaderStage::Fragment => {
                current_fs = Some(module_name.clone());
                current_bindings.extend(module.bindings.iter().cloned());
            }
        }
    }
    // flush 最后的 render phase
    if current_vs.is_some() || current_fs.is_some() {
        phases.push(flush_render_phase(&mut current_vs, &mut current_fs, &mut current_bindings));
    }
    phases
}
```

### 6.3 统一顶点布局合并

```rust
fn build_unified_vertex_layout(
    phases: &[ExecutionPhase],
    modules: &HashMap<String, ReflectedModule>,
) -> ShaderResult<(Option<VertexLayoutDescriptor>, VertexDataMapping)> {
    let mut location_map: HashMap<u32, VertexAttributeInfo> = HashMap::new();
    let mut function_subsets: HashMap<String, Vec<u32>> = HashMap::new();
    
    for phase in phases {
        let module_names = phase.module_names(); // 获取 phase 中的所有 module
        for name in module_names {
            if let Some(module) = modules.get(name) {
                let subset: Vec<u32> = module.vertex_attributes.iter()
                    .map(|a| a.location)
                    .collect();
                function_subsets.insert(name.clone(), subset);
                
                for attr in &module.vertex_attributes {
                    if let Some(existing) = location_map.get(&attr.location) {
                        // 冲突检测：同一 @location 不同类型
                        if existing.ty != attr.ty {
                            return Err(ShaderError::Reflect {
                                message: format!(
                                    "@location({}) conflict: '{}' ({:?}) vs '{}' ({:?})",
                                    attr.location, existing.name, existing.ty, attr.name, attr.ty
                                ),
                            });
                        }
                    } else {
                        location_map.insert(attr.location, attr.clone());
                    }
                }
            }
        }
    }
    
    if location_map.is_empty() {
        return Ok((None, VertexDataMapping { unified_layout: None, function_subsets, semantic_sources: HashMap::new() }));
    }
    
    // 按 location 排序，重新计算 offset
    let mut sorted_attrs: Vec<VertexAttributeInfo> = location_map.into_values().collect();
    sorted_attrs.sort_by_key(|a| a.location);
    let mut offset: u64 = 0;
    for attr in &mut sorted_attrs {
        attr.offset = offset;
        offset += attr.ty.byte_size();
    }
    let stride = offset;
    
    let layout = VertexLayoutDescriptor {
        attributes: sorted_attrs,
        stride,
        has_instance_data: false, // TODO: 检测 @builtin(instance_index)
    };
    
    Ok((Some(layout.clone()), VertexDataMapping {
        unified_layout: Some(layout),
        function_subsets,
        semantic_sources: HashMap::new(),
    }))
}
```

### 6.4 Binding 合并

```rust
fn merge_bindings(all_bindings: &[ShaderBinding]) -> ShaderResult<Vec<ShaderBinding>> {
    let mut merged: HashMap<(u32, u32), ShaderBinding> = HashMap::new();
    for b in all_bindings {
        let key = (b.group, b.binding);
        if let Some(existing) = merged.get(&key) {
            if existing.name != b.name && !existing.name.is_empty() && !b.name.is_empty() {
                return Err(ShaderError::BindingConflict {
                    group: b.group, binding: b.binding,
                    existing: existing.name.clone(), new: b.name.clone(),
                });
            }
        } else {
            merged.insert(key, b.clone());
        }
    }
    let mut result: Vec<ShaderBinding> = merged.into_values().collect();
    result.sort_by_key(|b| (b.group, b.binding));
    Ok(result)
}
```

### 6.6 CS 顶点数据传递

wgpu compute pass 不支持 `set_vertex_buffer()`。对于需要顶点数据的 CS：
- 编排器检测到 CS phase 的 `vertex_location_subset` 非空
- 自动生成一个 storage buffer binding（如 `@group(3) @binding(0) var<storage, read> vertex_data: array<VertexData>`）
- 应用层负责创建 GPU buffer 时同时设置 `VERTEX | STORAGE` usage flags
- 同一 buffer 在 render pass 中作为 vertex buffer，在 compute pass 中作为 storage buffer

## 9. 跨文件依赖处理策略

**核心约束**：naga 无法解析包含未定义引用的 WGSL（如 forward_plus.wgsl 引用 pbr_common 的 Camera 类型）。

**解决方案**：`reflect_module()` 要求传入已拼接的完整源码。调用方（pipeline_compiler 或应用层）负责拼接：

```rust
// 在 pipeline_compiler 中
fn prepare_source(module_name: &str, raw_source: &str, dependencies: &[(&str, &str)]) -> String {
    let mut source = String::new();
    for (dep_name, dep_source) in dependencies {
        source.push_str(dep_source);
        source.push('\n');
    }
    source.push_str(raw_source);
    source
}
```

这与当前 `shader_library.rs` 的 `format!("{pbr_common}\n{pipeline}")` 策略一致。

## 11. 风险与缓解

| 风险 | 严重度 | 缓解 |
|------|--------|------|
| naga 无法解析独立管线 shader | 高 | reflect_module 要求拼接后的完整源码；文档明确要求调用方负责依赖拼接 |
| post_bloom.wgsl 有 2 个 @fragment entry | 中 | extract_entry_points 返回所有 entry points；pipeline_compiler 为多 fragment 生成多个 render phase |
| fog.wgsl 的 texture_depth&lt;f32&gt; 语法 | 中 | 添加专门的 reflect 测试；如 naga 拒绝则添加容错处理 |
| 同一 @location 在不同 shader 中类型冲突 | 高 | build_unified_vertex_layout 中检测并报错 |
| CS 需要顶点数据但 wgpu 不支持 vertex buffer in compute | 中 | 自动注入 storage buffer binding；文档说明 buffer 需要 VERTEX\|STORAGE usage |
| ShaderModule 字段新增破坏性变更 | 低 | vertex_attributes 默认 Vec::new()，ShaderModuleDef trait 提供默认实现 |
| 非方阵类型（mat3x4 等）WgslType 不支持 | 低 | 映射为 WgslType::Custom(name)，后续按需扩展 |
| regex 性能开销 | 低 | 仅在反射阶段使用（非每帧），影响可忽略 |

## 12. 被否决的替代方案

**1. 纯文本解析（无 naga）**：否决。naga 已作为依赖存在，免费提供所有结构化信息。
**2. 纯 naga 提取（含 body 反编译）**：否决。naga IR 函数体是 Statement/Expression 图，还原 WGSL 文本需 2000+ 行。
**3. 保持按 stage 类型分组**：否决。用户要求扁平化混合列表。
**4. 参数手动声明**：否决。用户要求通过 naga 反射自动获取。
**5. per-phase 独立顶点布局**：否决。用户要求统一数据源 + 按需读取。
